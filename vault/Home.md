# POMS project notes

Notes for the **Parish Operational Management System with ML Kit OCR** (the `parishrecord` repo). Start here.

> [!warning] No register data in this vault
> Never paste names, birth dates, parents or photos from the registers here. They are parishioners' (and minors') records. Refer to a sample by file name, e.g. `IMG_3949`. See [[Data privacy rules]].
